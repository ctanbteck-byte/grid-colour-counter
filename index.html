Step 1 — Copy This Prompt Into Claude.ai
You are an expert OCR and counting system. I am attaching an image of a 32×32 grid where each cell contains a number representing a "numbered colour". Perform TWO independent passes then reconcile: PASS 1: Read every cell row by row, left to right, top to bottom. Record all 1,024 values. PASS 2: Re-read the image independently. For any cell where your reading differs from Pass 1, note it as a discrepancy [row, col, pass1_val, pass2_val] (0-indexed). RECONCILIATION: For discrepancies, use Pass 2 as the authoritative value. Count occurrences of each numbered colour in the final reconciled grid. SELF-CHECK: Verify total cells = 1,024. Set checksum_ok to false if not. Return ONLY this raw JSON — no explanation, no markdown fences, no extra text: {"total_cells":1024,"unique_colours":N,"checksum_ok":true,"confidence":"high|medium|low","discrepancies_reconciled":N,"notes":"brief observations","counts":[{"colour":1,"count":N},{"colour":2,"count":N}]}
